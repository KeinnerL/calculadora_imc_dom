

Calculadora de IMC (Índice de Masa Corporal)
Este proyecto es una calculadora interactiva de IMC desarrollada con HTML, CSS y JavaScript, que permite registrar personas y analizar su estado físico a partir de su peso y estatura. También muestra estadísticas generales como edad promedio, cantidad de personas con sobrepeso y más.

 Funcionalidades
Registro de personas con nombre, género, edad, peso y estatura.

Cálculo automático del IMC con clasificación:

Bajo peso

Normal

Sobrepeso

Obesidad

Registro acumulado de estadísticas:

Número total de hombres y mujeres

Personas menores de edad

Personas con sobrepeso

Edad promedio

Persona con menor IMC

🛠️ Tecnologías Usadas
HTML5

CSS3

JavaScript (vanilla)

🖥️ Cómo usar
Clona o descarga este repositorio.

Abre el archivo index.html en tu navegador.

Llena el formulario con tus datos y presiona Calcular IMC.

Puedes agregar múltiples personas y ver las estadísticas al presionar el botón Ver estadísticas.
